bi-export-plus
Real, binary .xlsx and typed JSON exports for the IRIS BI/DeepSee Analyzer

The Analyzer's stock "Export to Excel" button writes an HTML table with an .xls extension - Excel opens it, but it's not a real workbook. This adds an actual .xlsx (real cell types, number formats, a genuine Excel Table) and a typed JSON export, wired directly into the Analyzer's own Export dropdown. This container comes with Samples-BI preloaded, so everything below works immediately.
